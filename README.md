# selakap.github.io

Personal portfolio site for **Selaka Piumal** — Software Engineer / Integration Consultant. Live at [selakap.github.io](https://selakap.github.io).

## Structure

```
index.html          Main page (About, Skills, Experience, Education & Certifications, Key Projects, Get In Touch)
style.css           Site styling
script.js           Mobile navigation toggle
projects/           Standalone case study pages linked from the Key Projects section
```

### Case studies

- `assetvision-openspatial.html` — AssetVision ↔ OpenSpatial Asset Sync API
- `authority-narapi.html` — Authority NAR Contact Resolution API
- `forms-authority-cm10.html` — Authority / CM10 Public Forms Integration
- `paas-poc.html` — PaaS Self-Service Deployment Console
- `smart-wheelchair.html` — Smart Wheelchair — Multi-Modal Control Interface

## Tech

Static HTML/CSS/JS, no build step or dependencies. Hosted via GitHub Pages directly from this repo.

## Local preview

Open `index.html` directly in a browser, or serve the folder locally, e.g.:

```
npx serve .
```
